# Portfolio cá nhân – Nguyễn Kỳ Anh

## Sản phẩm này là gì?

Đây là website Portfolio cá nhân được xây dựng bằng HTML5 và CSS3, dành cho sinh viên Công nghệ thông tin nhằm giới thiệu bản thân, kỹ năng, quá trình học tập và các sản phẩm học tập.

## Demo

Chưa có đường dẫn GitHub Pages được xác nhận.

## Tính năng

- Giới thiệu thông tin cá nhân của Nguyễn Kỳ Anh.
- Hiển thị các kỹ năng và kiến thức đang học trong ngành CNTT.
- Giới thiệu các dự án và sản phẩm học tập.
- Sử dụng HTML5 với các thẻ HTML Semantic.
- Thiết kế giao diện bằng CSS3.
- Sử dụng CSS Grid và Flexbox để bố trí nội dung.
- Có thiết kế Responsive hỗ trợ các kích thước màn hình khác nhau.

## Cách mở

1. Mở thư mục chứa dự án Portfolio.
2. Mở file index.html bằng trình duyệt Google Chrome hoặc Microsoft Edge.
3. Sử dụng menu điều hướng để xem các nội dung trên website.

## Cấu trúc thư mục

- index.html: Trang chính của website.
- css/: Chứa các tệp định dạng giao diện.
- images/: Chứa hình ảnh sử dụng trên website.
- docs/: Chứa tài liệu hướng dẫn, minh chứng và nhật ký AI.
